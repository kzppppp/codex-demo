# ETF Quant T Advisor

一个面向 A 股 ETF 的轻量化量化参考工具：先扫描监控池，再定位最值得人工复核的 ETF，并给出可解释的做 T 风险区间。

## 这版改了什么

- **全池扫描**：一次读取监控池，按评分把“买入候选 / 等待 / 回避或减仓”排序，减少逐只输入代码的判断成本。
- **统一评分规则**：现价与 MA20、MA5/MA20、MACD、RSI、5 日动量、成交量和 ATR 共同评分，扫描页与单只详情使用同一套规则。
- **历史滚动验证**：用 t 日信号结算 t+1 日结果，扣除 12bp 摩擦成本，展示有效样本、历史胜率、平均净收益和最大回撤。
- **实时价格校准**：实时价只用于校准回踩区、止损线和目标区，指标使用已经完成的复权日线，减少实时价与历史 K 线错配。
- **轻量缓存与容错**：行情和历史数据短缓存，扫描时允许单只 ETF 暂时失败，不影响其余标的展示。
- **简洁页面**：首页先给候选表，再看单只决策卡；手机端也可以横向查看表格。

## 本地运行

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
uvicorn app:app --reload
```

打开 http://127.0.0.1:8000。

## API

- GET /api/symbols：监控池。
- GET /api/scan：全池排序结果。
- GET /api/analyze?symbol=159915：单只 ETF 详情、指标、历史验证和交易区间。
- GET /api/health：服务健康检查。

## 风险边界

历史胜率只是规则在历史样本上的统计，不能保证未来收益。ETF 仍有跳空、跟踪误差、流动性、手续费和滑点风险；页面只做研究参考，不会自动下单。实盘前应继续加入分钟级行情、真实成交回报、分品种费率、滑点和独立样本回测。
